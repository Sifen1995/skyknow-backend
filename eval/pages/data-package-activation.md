# Buying and activating data packages

Customers can buy a data package from the app, from a shop, or by using their balance.

## Steps
1. Choose a package by size and validity (daily, weekly or monthly).
2. Pay with airtime balance or telebirr.
3. Wait for the confirmation SMS. The package is active within a few minutes.

## Notes
A new package of the same type is added to the remaining data of the old one. Packages do not carry over after they expire. If no confirmation SMS arrives within 15 minutes, check the balance and contact care.
