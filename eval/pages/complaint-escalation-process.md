# Complaint escalation process

A complaint that the first agent cannot solve must be escalated and tracked.

## Steps
1. Record the complaint with the customer's number, the problem and any case numbers.
2. Give the customer a case number and an expected response time.
3. If the problem is not solved within 5 working days, escalate to the team leader.
4. If it is still not solved, the customer may ask for a review by the customer protection office.

## Notes
Always call back the customer when the case is closed.
