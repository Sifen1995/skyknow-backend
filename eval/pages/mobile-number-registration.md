# Registering a SIM with a valid ID

Every SIM must be registered to a verified owner before it is fully active.

## Documents needed
A valid government-issued ID is required. Foreign visitors use a passport. The ID must be original, not a photocopy, and must be the person's own.

## Steps
1. Check the ID and compare the photo with the customer.
2. Enter the ID details and capture a live photo.
3. Activate the SIM and send the confirmation SMS.
One person can register only a limited number of SIMs.
