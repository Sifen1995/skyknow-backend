# Router reset and WiFi password

Use this page when a customer forgot the WiFi password or the router stopped working.

## Change the WiFi password
1. Connect to the router by cable or WiFi.
2. Open the router's settings page and sign in.
3. Choose the WiFi settings and enter a new password.

## Factory reset
Hold the reset button for about ten seconds. This erases all settings, including the WiFi name and password, so use it only as the last step.
