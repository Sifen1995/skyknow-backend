# Checking data and airtime balance

Customers can check their airtime balance, data balance and package expiry date at any time.

## Ways to check
Use the self-service app, dial the balance code given on the SIM pack, or ask a care agent after verifying the caller.

## Notes
The balance shown right after a purchase can take a minute to update. Agents must never read out a full account history before the caller is verified.
